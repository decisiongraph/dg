## Description

We currently run three separate monitoring tools: Datadog for APM, CloudWatch for infrastructure metrics, and PagerDuty with custom integrations for alerting. The combined cost is $3.2K/month and engineers waste time context-switching between dashboards during incidents. Consolidating onto a single self-hosted stack (Prometheus + Grafana + Alertmanager) would reduce costs to near-zero and provide a unified view.

## Impact

- **Cost**: Eliminate $3.2K/month in SaaS monitoring costs ($38K/year savings)
- **Efficiency**: Single pane of glass for all metrics reduces incident response time
- **Prerequisite**: Self-hosted monitoring is required before the AWS migration (OPP-002) since CloudWatch won't be available for bare-metal servers

## Success Metrics

- All production metrics available in Grafana within 30 days
- Decommission Datadog and CloudWatch integrations
- Alert latency under 30 seconds (matching current PagerDuty performance)

## Non-Goals

- Log aggregation — handled separately via Loki (future work)
- Distributed tracing — keep Jaeger as-is for now
