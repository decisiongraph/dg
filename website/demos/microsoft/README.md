# Microsoft Decision Archive

Key strategic decisions in Microsoft's history, from the Altair BASIC in 1975 to Satya Nadella's appointment in 2014. Based on the [Acquired podcast](https://www.acquired.fm/episodes/microsoft) episodes. This is a sample [Decision Graph](https://decisiongraph.dev) project: every page on this site is generated by `dg export --site` from the Markdown files in [`website/demos/microsoft`](https://github.com/decisiongraph/dg/tree/main/website/demos/microsoft).

- **Decisions** (ODR, a project-local type in `.dg/schema.kdl`) cover founding, partnerships, hires and strategy.
- **Opportunities** (OPP) track the platform shifts Microsoft chased, won and lost.
- **Architecture decisions** (ADR) and **incidents** (INC) cover NT, Azure and the antitrust years.

## Architecture

The platform lineage the decisions in this archive built, from [Altair BASIC](docs/architecture/adr-001-develop-basic-for-the-altair-8800.md) to [Azure](docs/architecture/adr-003-azure-platform-as-a-service-first.md):

```d2
direction: right

basic: Altair BASIC (ADR-001)
dos: MS-DOS (ODR-005, ODR-006)
windows: Windows (ODR-007)
nt: Windows NT (ADR-002)
azure: Azure (ADR-003)

basic -> dos
dos -> windows
windows -> nt
nt -> azure
```

## Risks

> [!WARNING]
> The risks that shaped Microsoft's strategy.

### Regulatory action

Bundling Internet Explorer led to the DOJ antitrust case and a breakup order (INC-001).

### Platform shifts

The internet, mobile and cloud each threatened to make Windows irrelevant (OPP-004, OPP-007, OPP-005).
