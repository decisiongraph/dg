# Pied Piper Decision Archive

Strategic decisions from the compression company that (almost) changed the world, from HBO's *Silicon Valley*. This is a sample [Decision Graph](https://decisiongraph.dev) project: every page on this site is generated by `dg export --site` from the Markdown files in [`website/demos/pied-piper`](https://github.com/decisiongraph/dg/tree/main/website/demos/pied-piper).

- **Architecture decisions** (ADR) trace the middle-out algorithm through the platform, the Box and PiperNet.
- **Decisions** (ODR, a project-local type in `.dg/schema.kdl`) capture funding, principles and brand calls.
- **Incidents** (INC) record the lawsuits, the COPPA violation and the attacks on PiperNet.

## Architecture

How the product evolved on top of the middle-out compression engine ([ADR-001](docs/architecture/adr-001-middle-out-compression-algorithm.md)):

```d2
direction: right

engine: Middle-out compression {shape: hexagon}
platform: Enterprise platform (ADR-002)
box: The Box appliance (ADR-003)
pipernet: PiperNet (ADR-004)
coin: PiedPiperCoin (ADR-005)

engine -> platform
engine -> box
platform -> pipernet: superseded by
box -> pipernet: superseded by
pipernet -> coin: funded by
```

## Risks

> [!WARNING]
> The top business risks the founders kept running into.

### Intellectual property claims

Hooli claimed ownership of middle-out (INC-001). Clean-room development and IP counsel are now mandatory.

### Regulatory compliance

Collecting data from children without parental consent (INC-002) exposed the company to FTC fines.

### Network security

A 51% attack (INC-003) showed that decentralization is only as strong as its node distribution.
